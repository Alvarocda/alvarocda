# Hi, I'm Álvaro Claro

**Full-stack developer · Angular · Quarkus · DevOps · AI applications**

I build web systems that replace manual processes with reliable digital workflows. For eight years I've worked mostly on frontend, the part of the software people actually use every day, and I own the whole path: understanding the process, designing the screens, building the backend behind them, and putting the system into production.

I've contributed to public citizen-service platforms. One of them won 3rd place in a state award for efficiency and innovation, and another is an identification system that has helped families find each other after decades apart.

Lately I've been building AI applications on the Java stack I already use in production:

- RAG assistants that cite their sources and say "I don't know" instead of inventing an answer.
- Tool calling that connects the model to live data (weather, aviation METAR, sports tables) and cites it like any other source.
- Agent-driven development where every decision is recorded as a PRD, RFC, or ADR, so the project stays understandable after the agents are done.

I care about what keeps a system maintainable: code another developer can pick up, deployments that run without anyone uploading files by hand at night, and an environment that works the same on every machine.
